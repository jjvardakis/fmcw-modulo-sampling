# Referencing this repository

After uploading, cite the repository URL and the commit or release used for the report. A commit-specific link makes the numerical version identifiable. For example:

```latex
The MATLAB code and reproduction instructions are available at
\url{YOUR_GITHUB_REPOSITORY_URL}, commit \texttt{YOUR_COMMIT_SHA}.
```

Replace both placeholders with the actual uploaded repository and commit. Cite Feuillen and Bhandari (SSP 2025) separately for the underlying reconstruction method. The repository citation identifies this project's experiments and implementation version.
